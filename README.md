# آکادمی علی خدیور — وبسایت

این پروژه یک صفحه‌ی وب تک‌فایلی (single-file) است؛ تمام کدهای HTML، CSS و JavaScript به همراه فونت‌ها و تصاویر به‌صورت Base64 در همان یک فایل `index.html` جاسازی شده‌اند. برای انتشار، کافیست همین فایل را در هر سرویس میزبانی استاتیک (GitHub Pages، Netlify، Vercel، cPanel و...) قرار دهید — نیازی به build step یا نصب پکیج نیست.

## استفاده سریع

1. فایل `index.html` را در ریشه‌ی ریپازیتوری یا هاست خود قرار دهید.
2. اگر از GitHub Pages استفاده می‌کنید: در تنظیمات ریپازیتوری، Pages را روی branch اصلی (و مسیر `/`) فعال کنید.
3. سایت بدون نیاز به هیچ سرور یا دیتابیسی، همان لحظه در دسترس خواهد بود.

## ساختار

- تمام استایل‌ها داخل تگ `<style>` در `<head>` قرار دارند.
- تمام منطق تعاملی (فال‌نامه، مودال پیش‌نمایش دوره‌ها، انیمیشن‌های اسکرول، هدر و...) در تگ `<script>` انتهای فایل، پیش از `</body>`، نوشته شده.
- فونت‌ها (Abar) با `@font-face` و Base64 در بالای فایل embed شده‌اند — هیچ فایل فونت جداگانه‌ای لازم نیست.
- تصاویر (کاور دوره‌ها، عکس مدرس، پس‌زمینه‌ها) نیز به همین شکل Base64 داخل خود HTML هستند.

## نکات برای ویرایش‌های بعدی

- **دکمه‌ی تلگرام**: در بخش تماس، لینک دکمه‌ی «ثبت‌نام» فعلاً روی `#` است. کافیست `href="#"` را با لینک واقعی تلگرام یا فرم ثبت‌نام جایگزین کنید (عنصر با `id="telegram-btn"`).
- **دوره‌ی شاهنامه**: در بخش کلاس‌ها، وضعیت این دوره روی «در حال ضبط و تدوین...» تنظیم شده. وقتی دوره آماده شد، این متن و دکمه‌ی مرتبط را می‌توان به لینک ثبت‌نام واقعی وصل کرد.
- **محتوای نقشه‌ی یادگیری در پیش‌نمایش دوره‌ها**: در تگ `<script>`، شیء `COURSES` شامل توضیحات و نقشه‌ی راه هر سه دوره (فلسفه، تاریخ ایران، اساطیر یونان) است. این محتوا فعلاً پیش‌نویس است و در صورت وجود سرفصل دقیق‌تر از طرف استاد، قابل جایگزینی است.
- **فال‌نامه**: لیست ویدیوهای غزلیات حافظ در آرایه‌ی `halVideos` داخل اسکریپت قرار دارد؛ برای افزودن یا حذف ویدیو، همین آرایه را ویرایش کنید.

## مرورگرهای پشتیبانی‌شده

از ویژگی‌های مدرن CSS مثل `backdrop-filter`، `aspect-ratio` و `mix-blend-mode` استفاده شده که در تمام مرورگرهای امروزی (Chrome، Safari، Edge، Firefox نسخه‌های اخیر) به‌خوبی کار می‌کند.
